# 教师标签审核用工作释义

版本：v0.2，2026-10-23（Asia/Singapore）。本页20条均为指挥教师模型依据名称／父路径拟定、待验证的工作提案，适用于本轮已有材料的开发审核；未核实本地词库发布者的正式定义。正式词库不扩充、不改名、不分配概念ID。审核规则见[职责文档](TEACHER_REVIEW_PROTOCOL.md)。

## 版本与来源边界

v0.1先行记录分离工程、资源与环境化工两条提案；v0.2扩充为本轮实际涉及的20条，并保留真实来源路径。v0.1反馈原样保留，其工作释义文档快照及哈希单独保存在本地忽略的v0.2审核目录，不回写旧反馈。

仅分离工程沿用此前指挥端所查教学前言索引作为广义参照：[青岛科技大学分离工程课程教研组《分离工程》第二版前言](https://hgjxcgj03.qust.edu.cn/__local/9/57/CF/365133B51DA584CEF28CFFE07C5_BC3A0CFC_58493.pdf)。该文档日期为2017-01，非2026新版；2026-10-23取得的是web搜索索引前言文字，直接PDF访问超时，未核验全文。索引将膜分离列为分离工程研究前沿，不证明本地词库采用该定义。其余19条没有本地官方定义或新外部引用，均是教师模型假说，不伪造官方依据。

## 待验证工作提案

### 心脑血管药物药理

现有路径：医学 → 药理学 → 心脑血管药物药理；来源引用`row:180:L3:1`，词库F118，数组下标1（从0开始；L2无数组下标）。

工作释义：研究药物对心脑血管系统、相关疾病过程及药物作用机制的影响。

纳入：明确的心脑血管药理、药物作用或药物发现研究。

排除：仅出现某心脑血管疾病名称，不足以证明从事药物药理研究。

### 神经精神药物药理

现有路径：医学 → 药理学 → 神经精神药物药理；来源引用`row:180:L3:0`，词库F118，数组下标0（从0开始；L2无数组下标）。

工作释义：研究药物与神经系统或精神相关功能、疾病过程之间的作用与机制。

纳入：明确神经药理或精神药物药理研究；保留具体分支。

排除：神经分支证据不扩张为全部精神疾病研究能力。

### 中药心脑血管药理

现有路径：医学 → 中药学 → 中药心脑血管药理；来源引用`row:177:L3:8`，词库F115，数组下标8（从0开始；L2无数组下标）。

工作释义：研究中药及其组分对心脑血管系统的药理作用和机制。

纳入：中药复方、组分与心脑血管作用的直接研究陈述。

排除：中药名称、疾病名称孤立共现不足以确认。

### 药物学

现有路径：医学 → 药物学；来源引用`row:179:L2`，词库E117，数组下标None（从0开始；L2无数组下标）。

工作释义：以药物发现、药物性质、作用及相关研究为范围的宽层级工作释义。

纳入：靶点确证和药物发现等明确研究。

排除：不从该宽标签反推合成药物化学等特定子方向。

### 分离工程

现有路径：化学工程 → 化学工程与工业化学 → 分离工程；来源引用`row:101:L3:3`，词库F39，数组下标3（从0开始；L2无数组下标）。

工作释义：研究利用组分性质差异等实现分离、纯化的过程、机理、设备与过程设计。

纳入：明确膜分离、超滤、纳滤、膜蒸馏等分离过程研究。

排除：机构名、导航命中或未说明分离用途的材料研究不足以确认；不代表掌握全部分离方法。

### 资源与环境化工

现有路径：化学工程 → 化学工程与工业化学 → 资源与环境化工；来源引用`row:101:L3:10`，词库F39，数组下标10（从0开始；L2无数组下标）。

工作释义：关于以化学工程原理研究资源利用、污染控制和资源回收过程与技术的工作范围假说。

纳入：能够说明化工过程或技术关联的研究可进入候选。

排除：不能把所有水处理、环境治理、资源管理直接等同该标签；本地正式边界仍未确定。

### 城乡规划

现有路径：土木工程 → 建筑环境与结构工程 → 城乡规划；来源引用`row:137:L3:1`，词库F75，数组下标1（从0开始；L2无数组下标）。

工作释义：以城乡空间组织、发展及规划理论、方法、实践为对象的工作范围假说。

纳入：明确规划研究，或已有范围依据能承接的城市空间研究。

排除：城市历史或形态研究与规划相关，不自动证明二者存在本项目所需的上下位关系。

### 建筑学

现有路径：土木工程 → 建筑环境与结构工程 → 建筑学；来源引用`row:137:L3:0`，词库F75，数组下标0（从0开始；L2无数组下标）。

工作释义：研究建筑及其空间、历史、理论、设计等问题的宽层级工作释义。

纳入：明确建筑思潮、建筑理论及建筑历史研究。

排除：不据某一分支断言建筑结构工程或所有设计实践能力。

工作释义：研究新闻活动、媒介传播、受众及其社会关系的宽层级工作释义。

纳入：新闻生产、受众和媒介生活研究的明确陈述。

排除：所授课程或媒体工作经历本身不足以赋标；不自动补三级理论标签。

### 传播学理论

纳入：明确理论研究证据，或能说明研究与理论问题关系的材料。

排除：媒介或受众主题出现本身不证明以理论为主。

### 电化学

排除：涉及电力设备或出现电字不构成依据；不推断全部基础与应用分支。

排除：泛称功能材料研制不自动确认为某材料类别或此工程范围。
