# 教师小样审核规则

适用于教师简介的方向、证据与现有标签审核。Q1—Q7已经用户确认；术语见 [GLOSSARY](../GLOSSARY.md)。实际审核完成量及版本统一在 [EXPERIMENTS](EXPERIMENTS.md) 记录。

## 判断依据

- **方向与时效分别判断。** 简介明确自述方向而无更新时间时，可给标签建议，时效记未知。课程、任职、导航、单篇作品和旧项目分别记录证据角色，不能仅凭共现词推定专长。
- **按已确认包含关系作上位映射。** 保留细方向和原文，并明确较宽映射；仅相关、包含关系不清或只能部分表达的候选保留待审核。
- **优先减少错标，同时记录遗漏与拒判。** 标签数随证据，资料不足是允许的结果。初判没列出的标签不自动等于模型错，需回到原文及范围逐项判断。
- **释义保持来源和状态。** 对实际使用的标签补工作释义，写包含／排除范围，区分官方资料、模型推断与未知。本地发布者未确认的定义标待验证，正式词库不改。已冻结批次使用自己的释义快照，入口见[工作释义](TEACHER_LABEL_SCOPES.md)。
- **审核者来源如实记录。** 当前由指挥 Agent 作为教师模型审核，材料准备者负责记录和定位校验。反馈不称真人专家意见、独立金标、盲测答案或模型准确率。

## 新样例先判后比

1. 冻结最多20条材料及选择理由，排除旧16例和已知重复；记录短／长文、跨学科线索、实际正文语言与异常覆盖，缺层据实说明。完成条件：来源、原类型、哈希和完整原文可回查，材料不含旧标签或模型预测。
2. 指挥端依据原文、冻结词库及工作释义保存初判。完成条件：方向、引用、建议／待审／拒判理由及初判哈希已保存，尚未查看该批 DeepSeek 预测。正文与书目语言分开，双语重复叙述不计独立证据。
3. 准备并核查等长 API 副本，再按任务的请求上限运行既有工具。完成条件：隐私遮盖不破坏研究内容和偏移，导出回读一致；异常保留原类型在本地分流，API 只收简介及必要词库。
4. 保存预测后逐项对照。完成条件：每个新增、遗漏、范围差异、拒判和失败均关联原文／词库及初判；原预测与初判保持不变，复审结论另留版本。暂不能裁定的分歧保留待审。
5. 汇总诊断及实际用量。完成条件：记录分母、覆盖缺口、成功／失败／未运行、实际 token／耗时及费用来源，未知记 null；结果可支持后续实验建议，不能外推全量准确率。

步骤4—5是本项目的可追溯记录安排；不增加用户逐条复核门槛。旧16例已在开发中暴露，只承担校准，不能混入新样例的先判分母。

## 旧、新标签对照

2026-10-26用户提出用无旧标签材料重新标注后比较新旧。以下规定对照顺序；实际完成情况见 [EXPERIMENTS](EXPERIMENTS.md) 的 T-BERT-01，不改变已冻结批次或当前任务的请求上限。

1. 原表只读。实验输入省略旧标签，预测另存，以本地教师 ID 和来源行关联；不清空原表，也不把旧标签用于提示或初判。初判与预测阶段读取 A:O，S 列仅在后续对照阶段按步骤2读取；API 用户内容仅为脱敏简介与必要词库。
2. 等本批新预测冻结后再读取相应旧标签，生成本地对照记录。保留旧标签、新预测、先前初判与复审意见四种来源，不用复审结论覆盖它们。若随后调提示或词库，另存实验版本，不能回填首次预测。
3. 用同一原文与冻结工作释义逐项核查两套标签的证据支持、遗漏、范围过宽／过细、拒判与无法判断项。先核实旧、新概念身份及包含关系；可确认的细标签投影至共同层级比较覆盖，细粒度新增价值另列，不能把层级不同直接计作错误。历史输入与数据时点未核实时，结论只描述现有简介的支持程度，不把缺少现有证据直接归因于旧模型错误；来源未知项见[DATA_AUDIT](DATA_AUDIT.md)。
4. 由指挥 Agent 给出旧结果更有依据、新结果更有依据、两者均有依据或暂无法判断的逐项理由；保留证据不足与范围歧义。该结论是教师模型的开发审核，新旧一致率不称准确率，也不从本小样推断全表谁更准确。

若未来报告独立准确率，需要另设未参与调试的样本、独立答案和评价口径。该后续验证不增加当前小样的人工审批门槛。实际对照应在任务中明确验收并在 [EXPERIMENTS](EXPERIMENTS.md) 登记。

## 工具能力与解释限制

现有CLI校验结构、逐字引文位置和词库成员／路径。teacher_output_v2另检查每个自报supported方向自身至少含explicit_direction或research_activity角色的证据，覆盖无标签和仅scope_review标签的分支；仅兴趣用research_interest，弱线索可保留待审。role仍由模型声明，程序不从文本证明该角色正确，也不能判断引用是否足以支持summary全部主题／方法。

已确认包含关系的较宽映射在reason保留细方向与关系；仅相关、部分覆盖或范围不明用scope_review。旧DeepSeek CLI没有单独表达“时效未知”或“上位映射”的字段，这些仍在旧审核记录补充；新增离线profile单列时效未知、粒度及直接／派生，见下节。局部形式检查及新版提示不构成语义或概念包含关系审核。版本及旧契约回放边界见[操作指南](TEACHER_PATH_AND_TOOLS.md)。

旧 JSON 的 pending_human_semantic_review 等字段保持原样，新审核记录单独关联。模型自报 supported 与形式校验通过均不等于语义、当前时效或方向覆盖已经正确。

新样例中教师模型可用工作释义，当前 DeepSeek 工具使用来源词库名称／路径；不据此宣称两者信息条件相同或进行公平模型排名。非英语外文、未来独立验证人员及方法按实际覆盖另行确定。

## 证据决定粒度与映射状态

1. 每个方向独立保留原研究描述与逐字quote／Unicode偏移、证据角色，先判断是否支持本人研究，再判断标签概念关系和粒度。有据2级优先；有依据的同义、包含映射不要求标签全名逐字出现在简介。明确只支持现存0／1级时直接保留宽标签，不从宽类生成子类。时效无资料记未知，研究主题明确不等于已确认当前仍从事或适审资格。
2. 宽细与确定性分开：已确认宽映射可以supported，相关但范围／包含不明的细候选仍scope_review；粗化不能把未决变为确定。课程、任职、导航、他人研究和弱兴趣不能通过降为0级绕过本人研究要求。supported方向须自身含explicit_direction或research_activity声明；新profile中supported标签所连每个方向都须supported。程序校验声明一致性，无法证明角色、本人归属、持续专长或引文语义充分。
3. 词库未表达的细方向保留原文和gap；有据祖先可直接选择，19个无secondary分支可保留现有宽结果。不能补造细类、把宽结果计为2级成功，或凭同名合并跨父／跨层来源。路径和来源位置共同确定标签身份，来源引用不是正式概念ID。
4. 由supported细标签推得的祖先仅列为derived_projection，不增加独立专长／命中次数。显式直接宽标签须有自己的方向依据；同一方向同时提供supported子类及其supported祖先时，新入口拒绝冗余判断，要求输入者明确所需直接判断，而不静默改写。另一个独立方向可直接支持宽标签；它与机械投影分别保留。
5. 所有结果继续requires_review／semantic_validation=not_performed。细候选可服务未来优先发现、宽结果可补充发现并核查原文或成果，但不得以粒度单独给适审资格排序；共享父类不能证明能审其每个子领域。最终师稿相关性、误配／漏人及复核工作量需另行验证，本票不分配稿件。

本节适用于新增独立profile；旧teacher_output_v1/v2、旧预测及已冻结审核记录不变。入口、哈希与拒绝行为见[操作指南](TEACHER_PATH_AND_TOOLS.md#证据粒度离线profile25)。
