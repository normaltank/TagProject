# 教师任务范围与结果约定

本页维护用户要求及当前边界；阶段进度见 [STATUS](STATUS.md)，具体任务与验收见 [GitHub Issues](https://github.com/normaltank/TagProject/issues)。

## 当前用户要求

唯一活跃主线是教师简历／简介→研究方向→现有标签＋原文证据。先分流异常，再提取方向和证据、映射现有词库、完成可追溯的小样审核，依据结果决定是否扩大自动化。课程、任职、机构、导航和代表作中的偶现主题按各自证据角色判断。

教师标签的业务用途是为待审稿件匹配相应领域的审稿人。教师与稿件应使用可对齐的共用研究领域概念；稿件不是教师本人成果，不以作者或教师ID关联作为领域匹配前置。用户2026-10-28已提供待审稿件表并授权使用，来源及初检边界见[DATA_AUDIT](DATA_AUDIT.md)；当前先完成教师识别，稿件识别和匹配另按输入版本安排。

中文、外文和混写均是输入；外文不限英语，语言与文字脚本分别记录，未知保留未知。标签数量随证据，资料不足允许待核查或不赋标；具体判断统一见 [审核规则](TEACHER_REVIEW_PROTOCOL.md)。

已授权教师小样及 DeepSeek API 分类接入；已运行20条材料批次的范围及用量见[EXPERIMENTS](EXPERIMENTS.md)。新样例隔离旧16例及已知重复，先保存指挥 Agent 的教师模型初判，再看 DeepSeek 输出。已用额度不因修复或重试自动补回；后续live的输入版本与请求上限须在对应任务明确。当前不要求用户逐条真人复核；模型反馈属于开发证据，未来独立验证方式另定。

用户2026-10-31另授权[#15本地模型试跑](https://github.com/normaltank/TagProject/issues/15)：复用#12和#14共20条既有脱敏开发材料，比较现成encoder NLI分类头、encoder dense embedding和decoder embedding；限项目内隔离环境，必要依赖与公开模型下载合计10GiB、推理90分钟，不训练、不新增付费推理API调用、不重新读取原教师行或外发教师资料。具体候选与协议按该票固定；这不授权监督训练、历史BERT复现或扩大赋标，实际运行见[EXPERIMENTS](EXPERIMENTS.md#t-local-01三个本地模型的共同开发材料试跑)。

用户同日要求持续用本地大量数据推进工具选择和后训练结论，据此开展[#16扩大本地比较](https://github.com/normaltank/TagProject/issues/16)：固定120条新评价、10000弱训练、2000弱验证、1000吞吐输入，比较词法、现成NLI、两种embedding及冻结表示上的139 L2线性头。旧S仅作有来源弱监督；允许有界CPU头训练与仅据弱验证的对称优化，不更新主干。#16复用权重，新付费推理API／新模型下载0，小依赖≤250MiB、GPU累计≤4小时、研究产物≤8GiB，追加头优化CPU墙钟≤10分钟。材料、数量和参数是该票实验设计，不冒充用户逐项指定；实测、候选成果及当前建议集中在[扩大实验](EXPERIMENTS.md#t-scale-01扩大真实材料与冻结表示弱监督头)。

#16先保存主Agent AI初判，再读训练／弱验证S；校准工作点先锁定，才开放保留统计和评价S支持审计。评价／吞吐不参与训练、epoch或阈值选择，吞吐S始终不读。正文仅按既有方法等长遮盖，仍有残留身份及遮盖信息损失；当前只在本地使用。交付是可复用候选与待核语境，头没有自主证据定位；未扩大为全库正式自动赋标。#16本票不涵盖主干微调／LoRA、长训练、蒸馏、稿件分类及正式词库迁移，后续按新任务明确范围与预算。

用户2026-11-01要求继续实际比较其他工具和小规模参数适配，据此开展[#17证据判别](https://github.com/normaltank/TagProject/issues/17)：固定100条新材料、从旧539条主Agent AI意见按组派生90训练／30验证，比较四个固定基线、本地生成、三版NLI及专用重排共九路线。允许仅对NLI任务头及query/value低秩参数作有界适配，其他主干冻结；不把#16当时的票内排除项当作永久禁令。新增公开权重及必要依赖≤8GiB、GPU累计≤3小时、新版本研究产物≤10GiB、付费推理API0；教师内容仅本地，不全参数长训、不扩大正式赋标或改词库。数量、路线和预算是本轮有界设计，非用户逐项指定的永久限制。

#17新S始终不读。主Agent先冻结全部100条意见才开放新标签评分／生成，执行者可先作无标签特征编码；旧90/30训练须输入及协议核证后放行。全部代表与首预测冻结后先匿名审cal20，锁定工作点才开放held80质量。全文标签支持、引用存在和上下文语义充分分别记录；当前无据仅指固定输入不支持，不当现实研究领域负标签。初判、原预测和后审分开，后审不回调参数或输入，仍不称真人／独立金标。实际结果及复用入口集中在[EXPERIMENTS](EXPERIMENTS.md)。

API 用户内容仅含脱敏简介与必要词库，姓名／邮箱列、内部教师 ID 和历史标签留在本地；密钥仅由环境传给核心程序。当前小样授权覆盖第一阶段的“不调用付费 API／资料不外发”限制。全量赋标、长训练、平台部署和正式词库迁移仍未纳入范围。

## 结果约定

每条派生记录保留：

- 来源文件、sheet、行、字段、内部记录标识、原文版本及哈希；原件只读。
- 原文证据、Unicode 字符区间（起点含、终点不含）、语言及证据角色；转换后仍可回查原文。
- 研究方向、现有标签来源行／层级路径／出现位置、词库版本、映射状态与理由。
- 模型／提示／规则版本、失败或拒判原因、审核意见及修订来源；预测、初判和后续反馈分别保存。

旧标签可作历史方案对照、历史线索或经核验的训练数据，不直接当标准答案；其BERT来源与未知项见[DATA_AUDIT](DATA_AUDIT.md)。模型、短语与聚类发现进入候选审核，正式概念经治理发布。当前来源定位不冒充正式概念 ID；未来共同概念兼容性保留为接口约束。

公开仓库保存规则、脱敏汇总与代码；原始教师资料和逐条结果存于本地版本目录。数据结论的分母与来源见 DATA_AUDIT 或对应实验记录，外部依据注明官方来源及查阅日期。
