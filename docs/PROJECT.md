# 教师任务范围与结果约定

本页维护用户要求及当前边界；阶段进度见 [STATUS](STATUS.md)，具体任务与验收见 [GitHub Issues](https://github.com/normaltank/TagProject/issues)。

## 当前用户要求

唯一活跃主线是教师简历／简介→研究方向→现有标签＋原文证据。先分流异常，再提取方向和证据、映射现有词库、完成可追溯的小样审核，依据结果决定是否扩大自动化。课程、任职、机构、导航和代表作中的偶现主题按各自证据角色判断。

中文、外文和混写均是输入；外文不限英语，语言与文字脚本分别记录，未知保留未知。标签数量随证据，资料不足允许待核查或不赋标；具体判断统一见 [审核规则](TEACHER_REVIEW_PROTOCOL.md)。

已授权教师小样及 DeepSeek API 分类接入；下一批上限20条，隔离旧16例及已知重复，先保存指挥 Agent 的教师模型初判，再看 DeepSeek 输出。当前不要求用户逐条真人复核；模型反馈属于开发证据，未来独立验证方式另定。

API 用户内容仅含脱敏简介与必要词库，姓名／邮箱列、内部教师 ID 和历史标签留在本地；密钥仅由环境传给核心程序。当前小样授权覆盖第一阶段的“不调用付费 API／资料不外发”限制。全量赋标、长训练、平台部署和正式词库迁移仍未纳入范围。

## 结果约定

每条派生记录保留：

- 来源文件、sheet、行、字段、内部记录标识、原文版本及哈希；原件只读。
- 原文证据、Unicode 字符区间（起点含、终点不含）、语言及证据角色；转换后仍可回查原文。
- 研究方向、现有标签来源行／层级路径／出现位置、词库版本、映射状态与理由。
- 模型／提示／规则版本、失败或拒判原因、审核意见及修订来源；预测、初判和后续反馈分别保存。

旧标签可作历史方案对照、历史线索或经核验的训练数据，不直接当标准答案；其BERT来源与未知项见[DATA_AUDIT](DATA_AUDIT.md)。模型、短语与聚类发现进入候选审核，正式概念经治理发布。当前来源定位不冒充正式概念 ID；未来共同概念兼容性保留为接口约束。

公开仓库保存规则、脱敏汇总与代码；原始教师资料和逐条结果存于本地版本目录。数据结论的分母与来源见 DATA_AUDIT 或对应实验记录，外部依据注明官方来源及查阅日期。
