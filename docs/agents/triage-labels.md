# Triage Labels

| 技能角色 | 仓库标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 外部输入待判断 |
| needs-info | needs-info | 缺少解决问题所必需的信息 |
| ready-for-agent | ready-for-agent | 范围与验收明确，Agent 可按依赖顺序处理 |
| ready-for-human | ready-for-human | 有必须由人完成的步骤 |
| wontfix | wontfix | 决定不处理 |

标签描述任务条件，不指定使用哪个聊天。to-tickets 生成的任务直接使用 ready-for-agent；仍需遵守任务依赖。完成以 Issue 关闭状态及验收证据表示。
